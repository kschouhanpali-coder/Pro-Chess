**Pro Chess** delivers a full-featured chess experience with clean mechanics and a refined visual style. Built for both casual play and competitive matches, it combines smooth gameplay with a responsive, elegant interface inspired by premium strategy games — all running entirely in the browser.

## 🧑‍💻 Getting Started

Get a local copy up and running in three steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/kschouhanpali-coder/Pro-Chess.git
   ```
2. **Navigate into the project folder**
   ```bash
   cd Pro-Chess
   ```
3. **Open `chess.html`** in your browser and start playing ♟️

> No build tools, package managers, or servers required — it just works.
