# ♟️ PRO CHESS

A premium chess game built with **HTML5, CSS3, and JavaScript** — no installation required.

[![Play Pro Chess](https://img.shields.io/badge/▶_PLAY_NOW-c9a44c?style=for-the-badge&labelColor=0d0d0d)](https://kschouhanpali-coder.github.io/Pro-Chess/chess.html)
![License](https://img.shields.io/badge/license-MIT-c9a44c?style=flat-square)

---

## Features

- **Play vs AI** — 3 difficulty levels
- **Local 1v1** — Play with a friend
- **Time Controls** — 1, 3, 5, 10, 15, 30 minutes + Fischer increment
- **Move History** — Undo, navigate, resume
- **PGN Export** — Save and share games
- **Leaderboard** — Track statistics
- **Responsive** — Works on desktop & mobile

---

## Quick Start

**Online:** [Play Now](https://kschouhanpali-coder.github.io/Pro-Chess/chess.html)

**Locally:**
```bash
git clone https://github.com/kschouhanpali-coder/Pro-Chess.git
cd Pro-Chess
# Open chess.html in your browser
```

---

## How to Play

1. Choose game mode (AI or 1v1)
2. Select time control
3. Click or drag pieces to move
4. Export as PGN when done

## Tech Stack

- **HTML5** — Structure
- **CSS3** — Styling & dark-gold theme
- **JavaScript** — Game logic & AI
